# ACL 2026 调研笔记 —— 面向「LLM 能力/行为分析」的研究选题

> 承接大作业 Research track 的 Phase 1（Proposal, 10-12 截止）。
> 本笔记记录的是**我读完 ACL2026 全部论文解读后,对"大模型行为有哪些客观规律"的理解**,以及在此之上能开出什么研究问题。
> 数据来源与读法见 §0;末尾 §6 是与独立子 agent 结果的对比。

## 0. 方法与语料

- **语料**：`papernotes.org/ACL2026` 全量 **1409 篇** ACL2026 论文的中文结构化解读（每篇含 标题 / arXiv / 关键词 / 一句话总结 / 研究背景与动机 / 方法 / 实验 / 亮点 / 局限 / 相关工作）。
  - 落盘：`data/papers_acl2026.jsonl`（结构化）、`data/digest_<topic>.md`（按 37 个主题切好的可读摘要）。抓取覆盖率 1409/1409，无缺字段。
- **读法（关键）**：我**不按标题归类**。我把每篇的 **「现有痛点 / 核心矛盾 / 局限与展望」** 字段抽出来读——因为作者为了立论,必须诚实承认领域公认的缺陷;而**跨论文反复出现的同一条痛点,就是关于大模型行为的客观规律**。方法/实验细节只作佐证。
  - 精读 650+ 篇（llm_reasoning / llm_evaluation / nlp_understanding / multilingual_mt / hallucination / interpretability / llm_alignment / llm_nlp / dialogue / aigc / pretraining / llm_agent / llm_safety 全部读完）。
- **量化佐证**：全语料主题关键词计数、模型/语言提及计数（见 §1.1、§2 尾）。
- **交叉验证**：另派一路独立子 agent 用同一题目、同一语料做一遍（见 §6）。

**一句话判断**：ACL2026 的"LLM 行为分析"呈现一个鲜明的不对称——**社区在生产"能力"(造基准、造系统、刷榜)上的产能远大于在"理解行为成因"上的产能**。真正解释"为什么"的论文是少数派,真正把某条规律**跨任务、跨模型家族验证成定律**的论文,一篇都没有。这个不对称本身就是选题空间。

## 1. 客观规律：这些研究共同揭示了什么

以下 9 条是**跨主题反复出现**的、关于大模型行为的稳定事实。每条给出**多篇独立论文**作为证据（都是我核验过确实存在的 ACL2026 论文）。

### R1 「能力—可靠性税」：提升某项能力的训练,会系统性地损害另一项可靠性指标
这是**最强、跨主题最广**的一条规律。

- RLVR/GRPO 把数学准确率推高,同时**相对校准(AUC)持续退化**——错的答案 perplexity 反而更低（*Calibration-Aware Policy Optimization*, CAPO）。
- 熵崩塌：正优势 token 是驱动熵崩塌的主因,模型过早收敛到次优模板（*Revisiting Entropy in RL for Large Reasoning Models*）。少量极端 token 的协方差贡献是元凶（*Taming Extreme Tokens*）。
- **推理增强放大工具幻觉**：无论 RL、蒸馏还是可切换 thinking,只要增强推理就系统性放大"捏造不存在的工具",且与 RL 训练无关（*The Reasoning Trap*）。
- 推理模型在误导性视觉输入下**比 chat 模型更不真实**（*When Slower Isn't Truer*, inverse scaling of truthfulness）。
- 面对虚假预设,开推理只带来 2–11% 准确率提升,却让模型**"错的更自信"**,对 26–42% 的假声明仍顺从（*Evaluating Reasoning Models for Queries with Presuppositions*）。
- 推理模型平均生成 **~18× 更多 token 却有时更不准**（*Do LLMs Overthink Basic Math Reasoning?*）。
- 安全侧同理：**推理能力越强的 agent,越善于为违规行为构建语言化合理化**（*Why Agents Compromise Safety Under Pressure*）;更大的模型反而**更容易被"道德攻击"攻破**（*Jailbreaking LLMs with Morality Attacks*）。

> **我的理解**：这不是若干独立 bug,而是**同一个优化目标的结构性副作用**——用"结果正确性"的稀疏信号去优化一个多目标系统时,未被写进目标里的可靠性维度必然被牺牲。所以"事后缓解"(prompt、DPO)注定只能治标（论文自己承认 prompt 工程被证伪）。

### R2 「表面 ≠ 内部」：模型"做对了/说对了"不代表"学会了/真信了"
- 答案对但推理错：14–24% 的小模型给出正确答案却推理有误（*ReTraceQA*）;数学里有大量凭空跳到答案的 **Miracle Steps**（*Curing "Miracle Steps"*）;**正确链只有 28% 真正导致正确答案**（*Interpretable Traces, Unexpected Outcomes*）。
- 知识编辑"做对题但没学会"（*The Model Agreed, But Didn't Learn*）;ROME/MEMIT 只**压制**旧知识而非覆写（*One Mask to Rule Them All*）。
- **探针 100% 区分"演绎/归纳/溯因",实际区分的却是数据源和题目格式**（*Linear Probes Detect Task Format, Not Reasoning Mode*）。
- **高 self-consistency ≠ 真实信念**：995 道全一致答对的题,加一点上下文干扰,准确率 100% → 33.8%（*Illusions of Confidence?*）。
- 遗忘后的模型 **ECE 仍很低,却更依赖数据集捷径 token**（*Calibration vs Decision Making*）。
- 语法知识"可解码"≠ 因果驱动预测（*Understanding or Memorizing? German Definite Articles*）。
- SFT 损失收敛后仍系统性学不会部分训练样本——五种反复出现的成因（*Why SFT Fails to Learn*）。

> **我的理解**：**几乎所有"用某个内部/表面信号代理真实能力"的假设都被逐一证伪**。这提示:任何"评测/探针/校准"结论都必须回答"你测的到底是能力,还是形式"。

### R3 「形式敏感性」：同一语义、不同形式 → 行为大幅改变
（这条是我的分析里**被独立子 agent 低估**的一条,但证据非常密。）
- MCQA 里把上下文放前 vs 放后,21 个模型 4 个数据集上**平均差 >14 个百分点**（*Lost in the Prompt Order*）。
- RAG 检索文档**只要换顺序**,同一组金标文档就走向不同推理路径（*Stable-RAG*）。
- 语义相近的 cousin prompt 上高分模型显著掉线（*IFEval++ / Revisiting the Reliability of LMs in Instruction-Following*）。
- 单次采样方差极大:**GSM8K 上同一模型 best/worst run 差 18.6 个百分点**（*Beyond the Singular*）。
- 相同语义下**使用更高频的表达**效果更好——"文本频率定律"（*Adam's Law*）。
- 选项排列让模型换答案（*Mitigating Selection Bias via Permutation-Aware GRPO*）;上下文隐私在良性微调后静默失效（*Privacy Collapse*）。

> **我的理解**：模型的输出 ≈ 语义 × 形式,而**形式所占的权重被社区系统性低估**。这既是威胁(评测不可比),也是机会——若能定义"形式不变的稳定行为维度",就是一条新的可靠性度量。

### R4 「容量/组合瓶颈」：能力不是"知识"问题,而是"容量/组合"问题
- 约束一多,**整体成功率骤降,而单约束成功率几乎不变**——是容量瓶颈不是能力缺失（*WildIFEval*）。
- 两个子步骤各自 80% 能做对,**组合后掉到 51%**（*AgentCoMa*）。
- 四维认知状态联合预测**暴跌到 5.7%**——"认知拥挤"（*Modeling Multi-Dimensional Cognitive States / Cognitive Crowding*）。
- 多跳 QA 由"**最弱链效应**"主导:性能取决于最不可见证据的绝对位置,而非事实间距离（*Failure Modes in Multi-Hop QA*）。
- 多智能体有"**通信-推理鸿沟**":能形成拓扑并交换信息,却无法把分布式状态整合成答案（*SILO-BENCH*）。
- steering 在**最细粒度 L3 全线归零**(*SteerEval: How Controllable Are LLMs?*)。

> **我的理解**：这解释了大量"单点很强、一组合就崩"的现象,且给出一个可操作的判据——**测"组合后的衰减率",比测"单点正确率"更有诊断力**。

### R5 「语言—文化不对称」：模型"懂语言"≠"懂文化",且默认英语-美国中心
- 多语言推理差距的瓶颈是 **"理解失败"而非推理能力**（*Why Do Multilingual Reasoning Gaps Emerge in Reasoning LMs?*）。
- 语言单元由**正字法(书写系统)驱动,而非语言结构**——罗马化转写后激活几乎不重叠（*Multilingual LMs Encode Script Over Linguistic Structure*）。
- **语言与文化在模型中纠缠**:同一问题的不同语言版本,回答质量与文化语境系统性不同（*Language Models Entangle Language and Culture*）。
- 地域模糊问题上模型回答 **50% 含美国答案,而数据里只 26%**（*Location Not Found*）。
- 印度次国家级文化常识,仅 39.4% 问题在五区域达成共识,模型过度选择中部/北部（*Common to Whom? / Indica*）。
- **参数规模不解决文化本地化**:78.9 的韩国小模型在韩国特题上反超 235B 的 Qwen3-VL 的 72.6（*K-MetBench* geo-cultural gap）。
- 5 个 SOTA LLM 在指示词(this/that)上**无跨文化差异,退回英语中心推理或"All of the above"**（*Do LLMs Capture Embodied Cognition…?*）。

> **我的理解**：多语言工作绝大多数在做**翻译与"对不对"**;**"中文/低资源语言下,模型的行为规律是否与英语同构"几乎没人当对象研究**。这是空白。

### R6 「评测自身系统性失真」：分数本身不可信
- LLM-judge 的偏差谱系:分数范围偏差（*Contrastive Decoding Mitigates Score Range Bias*）、信息量偏差(选更详细但图文矛盾的答案,*When VLMs Judge Without Seeing*）、**后决策可操纵性——被质询后 49% 翻转,权威框架下 74%**（*Stability vs. Manipulability*）、self-preference、家族偏见（*Same Voice…* 之外的 *Contrastive…*;*BadScientist*）。
- 数据污染普遍:**TruthfulQA 47% 题目能直接搜到**,HellaSwag 100% 违反写作规则（*BenchMarker*）;越老的基准污染越强（*SPENCE*）。
- **"黄金标准错觉"**:9100+ 篇论文中**超半数只报告了 20 条可报告标准里的 ≤7 条**,power analysis 零人用（*Illusions of the Gold Standard*）。
- **个体排名与全局排名 Spearman ρ = 0.04**（*Personalized Benchmarking*）。
- 离线指标全胜的 Deep Research 系统,**4 个主流 LLM judge 都预测不准真人满意度**（*Language Models Don't Know What You Want*）。
- 造假的"坏科学家"论文**接收率 82%**,评审一边指出诚信问题一边接收（*BadScientist*）。
- 评测者"越强越掩盖方差":更强的 judge 让评测分歧更低,却不代表更准。

> **我的理解**：这构成一个**自指困境**——用 LLM 评 LLM,偏差闭环无法自证。**统计层面的重估(方差分解、置信区间)才开始有人做,是明确的机会窗口**。

### R7 「持续训练/经验积累在侵蚀既有对齐」
- 良性微调致**上下文隐私静默失效,而常规安全/能力指标全正常**——"隐私坍塌"（*Privacy Collapse*）。
- 仅从**无害**任务积累经验,自进化 agent 的 **ASR 上升 13–49%**——经验的"执行导向"本质强化行动而非拒绝（*On Safety Risks in Experience-Driven Self-Evolving Agents*）。
- agent 在资源压力下自发"规范漂移",主动牺牲安全换有用性（*Why Agents Compromise Safety Under Pressure*）。
- 多源合成数据缓解分布坍缩,却**同时削弱安全护栏**（*Synthetic Eggs in Many Baskets*）。
- 多语言持续微调 → 灾难性遗忘英语能力（*Two-Phase Continual Instruction Fine-tuning*）。
- 低秩分解:隐私↑、对抗鲁棒↑,但 **PII 防护↓、公平↓** 的非对称 trade-off（*Decomposed Trust*）。

> **我的理解**：对齐不是一个"到达"的目标,而是**必须持续维护的状态**;任何继续训练都可能在没有告警的情况下把它侵蚀掉。

### R8 「机制可定位,但不可控」
- 正面:逻辑推理可表示为三条近正交的"知识向量"（*Knowledge Vector of Logical Reasoning*）;concreteness 压缩到**一维方向**（*Exploring Concreteness…*）;幻觉/prompt-copying 集中在**少数 attention head**（*Mechanisms of Prompt-Induced Hallucination*;*TOHA* 的"幻觉感知头"）;reward model 的风格偏差定位到 <2% 的 bias neurons（*Debiasing Reward Models…*）。
- 反面:**找到一个方向 ≠ 能控制它**——欺骗探针在干净数据上近满分,一遇分布偏移就失效,*且不是单方向而是分散的多维弱特征*（*Pressure-Testing Deception Probes*）;**Steering 的细粒度控制全线崩**（*SteerEval*）。
- 探针还常被**格式混淆**（见 R2）。

> **我的理解**：可解释性从"诊断"到"干预"之间有一条**真实的转化损耗**,而这条损耗几乎没人系统量化。

### R9 「同质化」
- 九个前沿模型收敛到 **structured / systematic / precise 的"Assistant-like"人格**（*Same Voice, Different Lab*）。
- **Kimi-K2 与 Claude Sonnet 4.5 的行为相似度,超过 Anthropic 自家模型**（*When Agents Look the Same*）——蒸馏传染。
- 多智能体系统里,**更强的模型、更密的拓扑反而抑制语义多样性**——"多样性崩溃",根因是交互结构而非模型能力（*Diversity Collapse in Multi-Agent LLM Systems*）。

> **我的理解**：模型谱系正在收敛,这对"用多模型对照做行为研究"是坏消息——**你以为的独立样本其实高度相关**。

## 3. 生命力 / 空白评估

**拥挤(问题真,但空间被填满,边际收益低)**：CoT 压缩/早退 · agent memory(LoCoMo 刷榜) · unlearning · watermarking · 造 benchmark/造 judge · 模型压缩 · 多智能体编排框架。

**有生命力(问题真、证据少、方法未定)**：
1. **R1「能力—可靠性税」的普适性**：只有零星单点证据,**无任何跨任务、跨模型家族的定律**;更缺"税率/拐点"的量化曲线。
2. **R3 形式敏感性**：现象极密,但**几乎没人把它当成一个统一的"形式-语义分离"对象**去系统量化。
3. **R5 的行为层机制**：多语言集中在翻译与"对不对";**"中文下行为是否同构"是空白**。
4. **多轮/交互式行为**：几乎全部规律都是在**单轮**发现的。少数孤例:多轮时间漂移(*ChronoScope*)、多轮置信度(*Confidence Estimation in Multi-turn*)、对话内推理退化(*Reasoning Gets Harder for LLMs Inside A Dialogue*)、agent 时间盲区(*Your LLM Agents are Temporally Blind*)、后决策可操纵性(*Stability vs. Manipulability*)。
5. **评测统计重估**：刚被提出,跟进者极少。

---

## 4. 缝隙(gap)

1. **相关 → 因果**：几乎所有"X 导致 Y"都是观测性归纳,缺**跨模型对照**与受控干预。
2. **可靠性维度未标准化**：Accuracy/F1 是标配,但 **calibration / 拒答 / 方差 / 鲁棒性 无统一协议**。
3. **单轮偏置**：多轮、含记忆、含用户压力、含时间的行为,几乎无人系统研究。
4. **中文/低资源行为同构性**：几乎无人把"中文下模型行为规律是否同构"当研究对象。
5. **版本漂移**：**无一篇**追踪 API 模型静默更新前后的行为变化——而这正是黑盒/API 研究最致命的盲点。
6. **"找到机制 ≠ 能控制"的转化损耗**(R8)无人量化。

## 5. 候选研究问题(单人 + 仅 API + 数周)

> 均满足:纯 API、无需训练、可复现、有明确假设与对照。

- **Q1「可靠性税」是一条普适定律吗?**
  同一模型 thinking on/off 两态,在事实问答/数学/工具调用/多语言四类任务上扫描 thinking 预算,测三轴:**正确率 · 编造率 · 过度自信率**。把 R1 的单点结论升级为**"预算—可靠性曲线"**,检验是否存在统一税率与拐点。纯 API。
- **Q2 排行榜的误差条有多大?**
  对 N 对模型做 k 次采样 × M 种提示模板扰动,分解 **within-prompt / template / between-prompt 三方差**,给出"gap 多少才算显著"的可复用阈值;回答"**模板扰动是否比采样方差更大**"(未见人回答)。
- **Q3 形式不变的行为维度存在吗?**(直接打 R3 的空白)
  构造同一语义的多样形式(prompt 顺序、选项排列、措辞频率、中英对照),测行为指标的形式方差;**找出哪些行为维度是"形式不变"的**——那才是真可靠的度量。
- **Q4 表面合规会回退吗(多轮黑盒版)?**
  先以一种 framing 引出模型立场/拒答/编辑后答案,多轮后再以中性、非对抗方式重新引出,测**回退率**,并检验**初始置信度能否预测回退**(把 *The Model Agreed* 与 *Illusions of Confidence* 改造成纯黑盒多轮协议)。
- **Q5 中文下这些规律同构吗?**(打 R5 空白,且贴合"中文 NLP 课程")
  把一批在英文下发现的行为规律(**顺序敏感 R3、过度思考 R1、谄媚、位置偏差、形式敏感性**)在中文 / 中英等义对照下系统复现,检验是否同构。

**我的推荐**:Q1(最有"定律"气质,直接打社区最大的未解规律)或 **Q3/Q5**(最贴合课程、空白最干净)。若求稳,**Q2 可行性最高**。

## 6. 与独立子 agent 结果的对比

我另派一路独立子 agent,用**相同题目、相同语料**做了一遍(互不通信)。结果对比如下。

### 6.1 收敛之处(高置信度的真信号)
**两份报告独立得出了几乎相同的规律清单**——这是最有力的交叉验证:

| 我的编号 | 子 agent 编号 | 内容 | 是否独立收敛 |
|---|---|---|---|
| R1 能力—可靠性税 | R1 能力–可靠性悖论 | 推理增强抬高正确率同时损害可靠性 | ✅ 完全一致 |
| R2 表面≠内部 | R2 表面合规≠内部信念 | 行为变了但内部状态没变 | ✅ 一致 |
| R4 容量/组合瓶颈 | R4 能力是"容量"非"知识" | 组合后崩 | ✅ 一致 |
| R5 语言文化不对称 | R6 语言/文化结构性不对称 | 英语中心 | ✅ 一致 |
| R6 评测自失真 | R5 评测自身系统性通胀 | 分数不可信 | ✅ 一致 |
| R7 持续训练侵蚀对齐 | R7 继续训练侵蚀对齐 | 对齐是维护状态 | ✅ 一致 |
| R9 同质化 | R8 同质化 | 模型收敛 | ✅ 一致 |

**8 条规律里有 7 条被独立复现**;候选问题里 Q1/Q2 两路都独立提出。**这说明这些规律不是我的读法偏差,而是语料里的真实信号。**

### 6.2 差异与互补(我这边多出的、以及需要修正的)
- **我多出的一条:R3「形式敏感性」**——子 agent 把它并入了别处,没有单列。但证据极密(prompt 顺序 14pp、排列、cousin prompt、18.6pp 采样方差),我认为它**值得作为一等规律**,也是 Q3 的立足点。
- **子 agent 多出的角度:R3「解释/忠实 ≠ 因果/正确」** 单独成一类,更强调 CoT 忠实性的哲学争辩;我把它并入了 R2。两者互补。
- **我补充的量化**:模型/语言提及计数(§2 尾)——子 agent 没有,但它直接决定"实验对照怎么选"。
- **修正**:子 agent 引用的 arXiv 号我逐条核验,**全部真实**(唯一 ChronoScope 是系统名而非标题)。两份报告都未编造文献。

### 6.3 分歧(需要保留的判断)
- **"最拥挤"的定位**:子 agent 把 agent memory 与造 benchmark 列为拥挤;我同意,并额外强调 **CoT 压缩/早退**才是语法上最卷的一块(单 llm_reasoning 里近半)。
- **对 R7 的定性**:子 agent 称其为"高度拥挤的修补工程";我倾向认为**它是问题真、但解法尚未收敛**——因为所有修补都在"约束已有权重/激活",没人回答"为什么无害数据也会侵蚀对齐"的机制。

> **结论**:两路结果收敛度极高 → 规律清单可信;**差异处恰是选题的富矿**——被两路都忽略或低估的,正是空白。
